Define checked subtraction over mathematical natural numbers: subtractIfEnough(balance, amount) returns Result(DebitError, Nat), where DebitError has exactly the constructor insufficient. The caller supplies balance and amount as natural numbers, with no upper bound. When amount <= balance, return ok(balance - amount). After any successful result remaining, remaining + amount = balance and remaining <= balance. Return error(insufficient) exactly when balance < amount. Concrete witnesses must include zero/zero success, equal positive operands success, and underflow error. This fixture excludes machine-width encodings, host execution, physical resources, and temporal progress claims.
