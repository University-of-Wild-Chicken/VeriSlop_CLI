Implement a Python function solve(data) for a row filtering and projection pipeline.
The input is a JSON object with exactly the fields rows and minimum. minimum is a signed integer. rows is a list of JSON objects, each with exactly the fields tag, amount and enabled: tag is a Unicode string, amount is a signed integer and enabled is a Boolean.
Keep exactly the rows whose enabled field is true and whose amount is greater than or equal to minimum. Preserve original order and duplicates.
Return a JSON object with exactly the fields rows, total and count. Each output row has exactly the fields tag and amount, copied without alteration from its retained input row. total is the sum of retained amounts and count is the number of retained rows.
An empty result has rows equal to an empty list, total equal to zero and count equal to zero. Arithmetic is exact arbitrary-precision signed integer arithmetic. Preserve Unicode strings exactly, including empty strings, whitespace and combining characters.
Inputs outside the stated schema and environmental effects are outside this task's scope.
