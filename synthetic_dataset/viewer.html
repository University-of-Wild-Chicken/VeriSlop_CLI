This viewer displays measured results from the files you choose. Select both files together, or add them one at a time:

  1. A generated comparison.json contains both models and keeps all four arms separate. Or select runs/qwen-local-003/summary.json for totals, model identity, and run budgets.
  2. runs/qwen-local-003/results.jsonl for task scores, workflow failures, and concrete expected-versus-observed cases.
  3. Optionally add a task’s cases.json to inspect case inputs alongside recorded outputs.

You can also drag files onto this panel. An incomplete run is labeled as a snapshot. Missing artifacts, timeouts, and blocked workflows count as unsuccessful; they are included in the test denominator.
