Implement a Python function reserve(balance, amount) over unbounded natural numbers, including zero.
Return the tuple ("ok", balance - amount) when amount <= balance.
Return the tuple ("error", "insufficient") when balance < amount.
Every successful returned balance must be at most the original balance.
Reserving zero must succeed and return the original balance.
The two arguments and successful output are natural numbers; subtraction on the successful branch is ordinary exact subtraction.
Behavior on negative numbers, booleans, non-integers, JSON interfaces, machine overflow, physical resource bounds and temporal progress is outside this specification.
