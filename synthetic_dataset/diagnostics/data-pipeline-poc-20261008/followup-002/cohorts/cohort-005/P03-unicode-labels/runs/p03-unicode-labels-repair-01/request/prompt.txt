Implement a Python function solve(data) for a Unicode label pipeline.
The input is a JSON object with exactly the fields labels and prefix. labels is a list of Unicode strings and prefix is a Unicode string.
Remove exactly the labels that are the empty string. For every remaining label, concatenate prefix followed by that label. Preserve original order and duplicates.
Return a JSON object with exactly the fields labels and count. labels is the resulting list and count is its length. An empty result has labels equal to an empty list and count equal to zero.
Preserve Unicode text exactly. Do not trim whitespace or normalize combining characters. The prefix may be empty.
Inputs outside the stated schema and environmental effects are outside this task's scope.
