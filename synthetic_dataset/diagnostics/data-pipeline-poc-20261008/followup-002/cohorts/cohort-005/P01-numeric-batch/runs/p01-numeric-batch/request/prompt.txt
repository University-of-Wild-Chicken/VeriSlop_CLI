Implement a Python function solve(data) for a numeric batch pipeline.
The input is a JSON object with exactly the fields values, minimum and factor. values is a list of signed integers; minimum and factor are signed integers.
Keep each input value that is greater than or equal to minimum, in its original order, preserving duplicates. Multiply every kept value by factor.
Return a JSON object with exactly the fields values, total and count. values is the resulting list; total is the sum of that list; count is its length.
An empty result has values equal to an empty list, total equal to zero and count equal to zero. Arithmetic is exact arbitrary-precision signed integer arithmetic, including negative and zero factors.
Inputs outside the stated schema and environmental effects are outside this task's scope.
