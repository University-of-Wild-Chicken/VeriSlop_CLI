Software engineering task G04: Deterministic shortest route with three tie breakers

Implement solution.py with solve(data). Use only the Python standard library. Do not read files, use the network, print, or retain state across calls. All inputs conform to this specification; return JSON-compatible values. Input {n,edges,source,target}, n=1..10, directed edges [u,v,cost], positive integer costs 1..20. Return null if target is unreachable, otherwise {cost,path}, path a vertex list including endpoints. Choose by minimum total cost, then minimum edge count, then lexicographically smallest vertex list. Parallel edges and self-loops are allowed. source=target returns {cost:0,path:[source]}.

Implement a pure deterministic Python 3 function solve(data) in solution.py. Use only the standard library, no external I/O. The function receives a JSON value and returns a JSON-serializable value. Preserve the specified input/output structure and exact ordering.
