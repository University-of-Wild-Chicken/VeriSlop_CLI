Software engineering task A06: Bounded coin change with inventory tie breaking

Implement solution.py with a single solve(data) function. data and the return value must be JSON-compatible. Use Python 3 standard library only; perform no external I/O and do not read benchmark files. All supplied inputs satisfy the stated schema and bounds; no behavior is required for malformed input. Input {coins:[[positive_denomination,available_count],...],target}, at most 6 coin types, counts<=4, target>=0. Distinct types may have equal denomination. Return null if impossible, else {count,counts} with counts in input order, minimizing total number of coins, then lexicographically minimizing counts. Target zero uses zero of every type.

Implement a pure deterministic Python 3 function solve(data) in solution.py. Use only the standard library, no external I/O. The function receives a JSON value and returns a JSON-serializable value. Preserve the specified input/output structure and exact ordering.

Public examples (additional held-out cases will be scored):
[{"input": {"coins": [[1, 3], [2, 2], [3, 1]], "target": 4}, "output": {"count": 2, "counts": [0, 2, 0]}}, {"input": {"coins": [[2, 1]], "target": 3}, "output": null}]
