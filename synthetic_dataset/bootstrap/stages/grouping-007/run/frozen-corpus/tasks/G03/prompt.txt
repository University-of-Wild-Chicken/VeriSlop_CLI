Software engineering task G03: Negative-cycle propagation in shortest paths

Implement solution.py with solve(data). Use only the Python standard library. Do not read files, use the network, print, or retain state across calls. All inputs conform to this specification; return JSON-compatible values. Input {n,source,edges}, n=1..10, edges [u,v,cost] with integer cost -6..9. Return a length-n distance list from source. Unreachable vertices are null. A vertex reachable from a negative-cost cycle that is itself reachable from source is "-inf". Other vertices have their minimum integer walk cost; source starts at distance zero. Parallel edges and self-loops are allowed; an unreachable negative cycle must not affect output.

Implement a pure deterministic Python 3 function solve(data) in solution.py. Use only the standard library, no external I/O. The function receives a JSON value and returns a JSON-serializable value. Preserve the specified input/output structure and exact ordering.
