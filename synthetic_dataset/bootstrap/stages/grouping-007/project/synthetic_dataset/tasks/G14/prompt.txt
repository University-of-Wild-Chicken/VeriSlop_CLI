Software engineering task G14: Resource-constrained route with zero-cost cycles

Implement solution.py with solve(data). Use only the Python standard library. Do not read files, use the network, print, or retain state across calls. All inputs conform to this specification; return JSON-compatible values. Input {n,edges,source,target,budget}; n=1..8, budget=0..12. Directed edges [u,v,cost,resource] have nonnegative integer cost 0..8 and resource 0..4. Find a walk consuming at most budget. Rank feasible walks by (total cost,total resource,edge count,vertex-list lexicographic order). Return {cost,resource,path} for the best, or null if none. A zero-edge walk is allowed. Zero-cost/zero-resource cycles and parallel edges must terminate correctly; no arbitrary hop cutoff.

Implement a pure deterministic Python 3 function solve(data) in solution.py. Use only the standard library, no external I/O. The function receives a JSON value and returns a JSON-serializable value. Preserve the specified input/output structure and exact ordering.
