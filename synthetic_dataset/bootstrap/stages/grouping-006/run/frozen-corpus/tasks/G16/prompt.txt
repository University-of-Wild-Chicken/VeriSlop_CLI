Software engineering task G16: Byte-weighted LRU with atomic replacement rejection

Implement solution.py with solve(data). Use only the Python standard library. Do not read files, use the network, print, or retain state across calls. All inputs conform to this specification; return JSON-compatible values. Input {capacity,events}, nonnegative capacity. Events: {op:"put",key,value,size}, {op:"get",key}, {op:"delete",key}. Keys ASCII, values integers, sizes positive. A put larger than capacity returns false and changes nothing, including an existing value or recency. Other puts remove an existing key, evict least-recently-used keys until the new size fits, insert as most recent, and return true. Hit get returns value and makes key most recent; miss returns null. Delete returns existence and removes key. Return {results,order,used}; order is LRU to MRU.

Implement a pure deterministic Python 3 function solve(data) in solution.py. Use only the standard library, no external I/O. The function receives a JSON value and returns a JSON-serializable value. Preserve the specified input/output structure and exact ordering.
