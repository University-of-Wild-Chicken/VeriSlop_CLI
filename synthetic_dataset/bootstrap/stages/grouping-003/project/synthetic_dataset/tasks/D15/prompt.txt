Software engineering task D15: Tab-aware block dedent and reindent

Implement solution.py with a pure solve(data) function. Input and output are JSON-compatible Python values. Use Python standard library only, no external I/O. Input {text:string,tab_width:positive int,indent:nonnegative int}. Split on LF preserving final empty line. Prefix indentation consists only of space/tab; space advances one column and tab advances to next multiple of tab_width from column zero. Determine minimum prefix column count among lines with non-space/tab content. For each such line replace indentation with spaces equal to original columns minus minimum plus indent, preserving content exactly. Blank lines become empty regardless of original indentation. Return {text:LF-joined transformed lines,removed_columns:minimum}; if all blank minimum is zero. CR is content, not a newline or indentation.

Implement a pure deterministic Python 3 function solve(data) in solution.py. Use only the standard library, no external I/O. The function receives a JSON value and returns a JSON-serializable value. Preserve the specified input/output structure and exact ordering.

Public examples (additional held-out cases will be scored):
[{"input": {"indent": 1, "tab_width": 4, "text": "\talpha\n  beta\n \t"}, "output": {"removed_columns": 2, "text": "   alpha\n beta\n"}}, {"input": {"indent": 3, "tab_width": 8, "text": " \t\n\t"}, "output": {"removed_columns": 0, "text": "\n"}}]
