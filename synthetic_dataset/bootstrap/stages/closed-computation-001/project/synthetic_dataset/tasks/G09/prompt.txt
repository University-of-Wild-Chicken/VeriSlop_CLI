Software engineering task G09: Canonical maximum bipartite assignment

Implement solution.py with solve(data). Use only the Python standard library. Do not read files, use the network, print, or retain state across calls. All inputs conform to this specification; return JSON-compatible values. Input {left,right,edges}, each side size 0..6; edges [left_index,right_index], duplicates allowed. Return {size,pairs}, a maximum-cardinality matching. Tie-break by lexicographically minimizing the length-left assignment vector, using right (the side size) as the unmatched sentinel. Thus matching an earlier left vertex beats leaving it unmatched. Output pairs sorted by left index. No vertex may appear in more than one pair.

Implement a pure deterministic Python 3 function solve(data) in solution.py. Use only the standard library, no external I/O. The function receives a JSON value and returns a JSON-serializable value. Preserve the specified input/output structure and exact ordering.
