Software engineering task D09: Revision-aware tombstone log reducer

Implement solution.py with a pure solve(data) function. Input and output are JSON-compatible Python values. Use Python standard library only, no external I/O. Input {events:[{key:string,revision:nonnegative integer,op:'put'|'delete',value:JSON for put}]}. Process in input order. First event for a key wins initially; later event replaces it only when revision is strictly greater. Equal or lower revision events are ignored even if operation differs. Deletes retain tombstone revisions so stale puts cannot resurrect. Return {items:[{key,revision,value}],tombstones:[{key,revision}],ignored:[original indices]}, items and tombstones independently sorted by key, ignored ascending input order. Keys can be empty. No compaction or revision arithmetic.

Implement a pure deterministic Python 3 function solve(data) in solution.py. Use only the standard library, no external I/O. The function receives a JSON value and returns a JSON-serializable value. Preserve the specified input/output structure and exact ordering.

Public examples (additional held-out cases will be scored):
[{"input": {"events": [{"key": "x", "op": "delete", "revision": 2}, {"key": "x", "op": "put", "revision": 1, "value": 5}, {"key": "x", "op": "put", "revision": 3, "value": null}]}, "output": {"ignored": [1], "items": [{"key": "x", "revision": 3, "value": null}], "tombstones": []}}, {"input": {"events": [{"key": "b", "op": "put", "revision": 0, "value": 1}, {"key": "b", "op": "delete", "revision": 0}]}, "output": {"ignored": [1], "items": [{"key": "b", "revision": 0, "value": 1}], "tombstones": []}}]
