Software engineering task D03: Recursive configuration interpolation

Implement solution.py with a pure solve(data) function. Input and output are JSON-compatible Python values. Use Python standard library only, no external I/O. Input {variables:{name:string},targets:[names]}; return an array of per-target results. Recursively substitute '${NAME}' where NAME matches [A-Za-z_][A-Za-z0-9_]*. '$${' becomes literal '${' and its following text is not expanded on a second pass. Everything not matched by these tokens stays literal. Evaluate matches left to right and stop at the first failure. Success {value:string}; unknown variable {error:'missing',name}; cycle {error:'cycle',path:[cycle names including repeated final name]}, using the active recursion suffix from the first repeated variable. Each target has independent evaluation; no external environment.

Implement a pure deterministic Python 3 function solve(data) in solution.py. Use only the standard library, no external I/O. The function receives a JSON value and returns a JSON-serializable value. Preserve the specified input/output structure and exact ordering.

Public examples (additional held-out cases will be scored):
[{"input": {"targets": ["A", "Z"], "variables": {"A": "${B}:$${B}", "B": "ok"}}, "output": [{"value": "ok:${B}"}, {"error": "missing", "name": "Z"}]}, {"input": {"targets": ["A"], "variables": {"A": "${B}", "B": "${C}", "C": "${B}"}}, "output": [{"error": "cycle", "path": ["B", "C", "B"]}]}]
