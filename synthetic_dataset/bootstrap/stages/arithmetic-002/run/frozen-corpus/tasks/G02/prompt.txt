Software engineering task G02: Canonical strongly connected condensation

Implement solution.py with solve(data). Use only the Python standard library. Do not read files, use the network, print, or retain state across calls. All inputs conform to this specification; return JSON-compatible values. Input {n,edges}, n=0..10, directed [u,v] edges; duplicates/self-loops are permitted. Return {components,dag}. Each strongly connected component is a sorted vertex list. Sort components by their smallest vertex; these positions are component IDs. dag is the sorted, duplicate-free list [component_u,component_v] of edges between distinct components. Isolated vertices are singleton components. For n=0 both lists are empty.

Implement a pure deterministic Python 3 function solve(data) in solution.py. Use only the standard library, no external I/O. The function receives a JSON value and returns a JSON-serializable value. Preserve the specified input/output structure and exact ordering.

Public examples (additional held-out cases will be scored):
[{"input": {"edges": [[0, 1], [1, 0], [1, 2], [2, 2], [3, 4], [4, 3]], "n": 5}, "output": {"components": [[0, 1], [2], [3, 4]], "dag": [[0, 1]]}}, {"input": {"edges": [], "n": 0}, "output": {"components": [], "dag": []}}]
