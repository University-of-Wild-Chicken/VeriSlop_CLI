Software engineering task G32: Three-way record merge distinguishing deletion from null

Implement solution.py with solve(data). Use only the Python standard library. Do not read files, use the network, print, or retain state across calls. For each key in the union: if local=remote choose that value; else if local=base choose remote; else if remote=base choose local; otherwise conflict. Choosing absence deletes the key. Return {merged,conflicts}; conflicted keys are absent from merged. Conflicts sorted by key, each {key,base,local,remote}, where each value is encoded {present:false} for absence or {present:true,value:v} for presence, including null. Do not recursively merge; object values are only the specified scalar types.

Implement a pure deterministic Python 3 function solve(data) in solution.py. Use only the standard library, no external I/O. The function receives a JSON value and returns a JSON-serializable value. Preserve the specified input/output structure and exact ordering.
