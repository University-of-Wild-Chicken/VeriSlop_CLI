Software engineering task G08: Maximum flow and canonical residual cut

Implement solution.py with solve(data). Use only the Python standard library. Do not read files, use the network, print, or retain state across calls. All inputs conform to this specification; return JSON-compatible values. Input {n,edges,source,sink}, n=2..8, source!=sink; directed edges [u,v,capacity] with capacity 0..9. Parallel capacities add; self-loops are allowed. Compute an integral maximum flow. Return {flow,reachable}, where reachable is the sorted vertices reachable from source by positive residual-capacity edges in a maximum-flow residual graph. To fix the computation, use Edmonds-Karp BFS, visiting neighbors in increasing vertex order, augmenting full bottlenecks. Residual reverse capacities add to any pre-existing opposite edge capacity.

Implement a pure deterministic Python 3 function solve(data) in solution.py. Use only the standard library, no external I/O. The function receives a JSON value and returns a JSON-serializable value. Preserve the specified input/output structure and exact ordering.
