# Focused source controls, before test source

Run one bounded generic Python unittest suite, registered with exact source/input hashes before execution. It may import the evidence-only parser, the authenticated frozen independent reconstruction helper, and the old/new factories solely to render fixed recipe strings. It must never invoke the producer agent_message API, execute a VIEW/template, access a fixture/expected answer, invoke a model/compiler/task, install source, or qualify a runtime claim.

The controls cover reported literal failures, unavailable UNKNOWN failures, and successful-looking five-key objects that remain unsuccessful. Native four-key responses and unauthorized fixture branches are rejected by this parser. Closed key sets, observed reference allowlist membership, authority overclaims, enum bounds, exact integer/bool distinction, VIEW/CONFIRM bounds, duplicate JSON keys, float/nonfinite/unsafe integers, malformed UTF8 and lone surrogates receive concrete negative inputs and exact rejection codes. Opaque diagnostic strings remain data.

Source fidelity compares the complete carrier AST after restoring only the old instruction literal, unchanged bytes outside that literal, the exact old instruction prefix and appended registered instruction. Six constant literals and all other function ASTs remain exact. The copied factory differs only in its sourceSHA literal and renders identical fixed collector recipes for unrelated references and registered closed parameters. Independent reconstruction validates the source-derived literal profile, reconstructs the whole message without the producer message API, preserves all FIRST/NEXT/CONFIRM/HASH recipe strings, and rejects stale or tampered source/profile data.

All 27 claim IDs and their frozen complete source documents are read-only guard inputs. The controls provide source preparation evidence only, with no inspection, historical cause, successful author, proof or qualification authority. Retain actual process PID, numeric exit status, output bytes and before/after input guards. Any concrete failed control is retained and repaired only after an explicit source amendment.
